# EVA
## **E**volution of **V**iable **A**ntibiotics

**EVA** is a quality-diversity optimization framework for the *de novo* generation of antimicrobial molecules. Antibiotics are extremely diverse, and conventional optimization frequently exploits data and predictor models' biases. Rather than searching for one optimal solution and discarding good candidates, we can define behavior dimensions (in this case, physicochemical properties) for molecules to compete only within the same niche.


The optimization engine is based on **Covariance Matrix Adaptation MAP-Annealing (CMA-MAE)**, implemented with the **pyribs** quality-diversity library. Candidate molecules are generated by searching the latent space of the **ChemBed** variational autoencoder (VAE), allowing evolutionary search to operate on a continuous representation of molecular structures.

Each generated molecule is evaluated using a **TabPFN** classifier trained on the public **[GNEtolC](https://github.com/Genentech/gneprop)** dataset. Activity predictions are made using a feature representation consisting of:

- **ECFP (512-bit) fingerprints**
- **MACCS keys**
- **200 molecular descriptors** computed with **Descriptastorus**

The optimization objective is the predicted probability that a molecule is antimicrobial. To encourage exploration and diversity, EVA organizes solutions in a configurable behavior space defined by any combination of the following dimensions:

- **LogP** — lipophilicity (RDKit `MolLogP`).
- **TPSA** — topological polar surface area (RDKit `TPSA`).
- **MW** — molecular weight (RDKit `MolWt`).
- **Fsp3** — fraction of sp3 carbons (RDKit `FractionCSP3`).
