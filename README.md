# EVA
## **E**volution of **V**iable **A**ntibiotics

**EVA** is a quality-diversity optimization framework for the *de novo* generation of antimicrobial molecules. Rather than searching for a single optimal candidate, EVA explores chemical space to discover a diverse collection of molecules with high predicted antimicrobial activity across multiple dimensions that serve as a gauge for risk and chemical desirability.

The optimization engine is based on **Covariance Matrix Adaptation MAP-Annealing (CMA-MAE)**, implemented with the **pyribs** quality-diversity library. Candidate molecules are generated by searching the latent space of the **ChemBed** variational autoencoder (VAE), allowing evolutionary search to operate on a continuous representation of molecular structures.

Each generated molecule is evaluated using a **TabPFN** classifier trained on the public **[GNEtolC](https://github.com/Genentech/gneprop)** dataset. Activity predictions are made using a feature representation consisting of:

- **ECFP (512-bit) fingerprints**
- **MACCS keys**
- **200 molecular descriptors** computed with **Descriptastorus**

The optimization objective is the predicted probability that a molecule is antimicrobial. To encourage exploration and diversity, EVA organizes solutions in a configurable behavior space defined by any combination of the following dimensions:

- **[BR-SA Score](https://link.springer.com/article/10.1186/s13321-024-00879-0)** — a retrosynthesizability/synthetic accessibility measure.
- **Applicability Domain** — the mean Tanimoto distance to the five nearest molecules in the training set.
- **LogP** — lipophilicity (RDKit `MolLogP`).
- **TPSA** — topological polar surface area (RDKit `TPSA`).

Dimensions are toggled on/off via the `dimension_enabled` array in `config.toml`. The resulting archive contains high-performing molecules spanning different regions of chemical space, providing a diverse set of promising antimicrobial candidates rather than a single optimum.


## Prerequisites

- [micromamba](https://mamba.readthedocs.io/en/latest/) or [conda](https://docs.conda.io/en/latest/)
- CUDA-capable GPU (TabPFN and ChemBedVAE run on GPU)

## Installation

### 1. Create the environment

```bash
micromamba create -f environment.yaml -n eva
micromamba activate eva
```

### 2. Install `--no-deps` packages

Two packages must be installed with `--no-deps` to avoid dependency conflicts:

- **chembed** — its full dependency tree pulls `tensorflow` and a second `torch` install,
  which conflicts with the conda-installed PyTorch
- **BRSAScore** — depends on `rdkit-pypi`, which conflicts with the conda-installed `rdkit`

```bash
pip install --no-deps chembed BRSAScore==0.1.1
```


### Verify

```bash
python -c "import rdkit; import torch; import tabpfn; import ribs; import chembed; from BRSAScore import SAScorer; print('OK')"
```

## Usage

```bash
python EVA.py  # uses config.toml (default)
python EVA.py --config my_config.toml
python EVA.py --resume results/<run_name>/scheduler.joblib  # resume from checkpoint
```

The loop will:
1. Load ChemBedVAE from HuggingFace
2. Load TabPFN activity predictor and AD scorer from `data/predictor/`
3. Generate seed molecules and evaluate them
4. Run CMA-MAE for `n_generations`, saving the archive and a heatmap to `results/<run_name>/`

## Configuration

All parameters live in `config.toml` (parsed by `config.py` into dataclasses):

| Section | Key parameters |
|---|---|
| `[archive]` | `solution_dim`, `dims`, `ranges`, `dimension_names`, `dimension_enabled`, `learning_rate`, `threshold_min` |
| `[emitter]` | `sigma0`, `batch_size`, `n_emitters` |
| `[generative]` | `model_repo_id`, `device`, `latent_dim`, `n_seeds`, `seed` |
| `[ad]` | `ad_model_path`, `n_neighbors`, `n_bits`, `radius`, `max_cache_size` |
| `[activity]` | `model_path`, `device`, `softmax_temperature` |
| `[run]` | `n_generations`, `eval_every`, `seed`, `resume_from` |
| `[output]` | `output_dir`, `run_name` |
| `[tensorboard]` | `enabled`, `log_dir`, `scalar_every`, `histogram_every`, `figure_every` |

## Project structure

```
EVA.py                  # Main evolution loop entrypoint
config.py               # ExperimentConfig dataclass + TOML loader
config.toml             # Active experiment configuration

featurization/
  features.py           # MoleculeFeaturizer (Morgan + RDKit descriptors + MACCS)
  morgan.py             # Morgan fingerprint utilities
  tanimoto.py           # Batch Tanimoto top-k distance computation
  build_ad_model.py     # Build kNN applicability domain model from CSV

generative/
  __init__.py           # ChemBedVAE wrapper

prediction/
  activity.py           # TabPFN load / predict / predict_from_features
  model_utils.py        # move_model_to_device (KV-cache aware)

scoring/
  br_sascore.py         # BR-SAScore wrapper
  ad_scorer.py          # ADScorer (kNN distance from predictor training data)
  physchem.py           # PhysChemScorer (LogP, TPSA)

optimization/
  loop.py               # CMAMAELoop + build_scheduler
  evaluator.py          # Evaluator class + EvalResult dataclass
  persistence.py        # save_archive / load_archive / save_scheduler
  constants.py          # Sentinel values
  reporting.py          # Rich console tables
  visualization.py      # Grid archive heatmap
  plotting.py           # Parallel axes figure
  tensorboard.py        # TensorBoard logging

data/predictor/         # Pre-fitted models (tabpfn, ad_model)
tests/                  # pytest test suite
results/                # Output directory
```
